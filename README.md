# 📊 Desafio Técnico – Manipulação e Limpeza de Dados

## 📖 Sobre o Projeto

Este projeto foi desenvolvido como parte do Bootcamp de Dados da UOL Compass.

O desafio consistiu em realizar a ingestão, extração, limpeza, transformação e padronização de dados provenientes de diferentes fontes, simulando situações comuns encontradas em ambientes corporativos e projetos de engenharia de dados.

Os dados apresentavam inconsistências típicas do mundo real, como formatos diferentes, registros duplicados, campos compostos e informações incompletas, exigindo um processo estruturado de tratamento para torná-los adequados para análises futuras.

---

## 🎯 Objetivo

Preparar e organizar dados provenientes de duas fontes distintas:

- Arquivo HTML contendo informações de livros estruturadas em tabelas.
- Arquivo CSV contendo registros financeiros com inconsistências de qualidade.

Ao final do processo, o objetivo era gerar um dataset limpo, consistente e pronto para consumo analítico.

---

## 🛠️ Tecnologias Utilizadas

- Python
- Pandas
- NumPy
- Jupyter Notebook
- HTML Parsing

---

## 🔄 Etapas Desenvolvidas

### 1. Ingestão dos Dados

Leitura e carregamento dos arquivos disponibilizados para o desafio:

- Extração das tabelas presentes no arquivo HTML.
- Importação dos dados financeiros armazenados em CSV.

---

### 2. Extração de Dados HTML

Utilização do Pandas para identificar e extrair automaticamente as tabelas contidas na página HTML, convertendo-as para estruturas tabulares adequadas para análise.

---

### 3. Limpeza dos Dados Financeiros

Foram realizados diversos tratamentos para garantir a qualidade dos dados:

- Correção de valores inconsistentes.
- Tratamento de dados ausentes.
- Remoção de registros duplicados.
- Padronização de formatos monetários.
- Padronização de datas.
- Conversão dos tipos de dados para formatos adequados.

---

### 4. Transformação dos Dados

Após a limpeza, os dados passaram por transformações adicionais para melhorar sua estrutura e facilitar análises futuras:

- Separação de campos compostos.
- Ajuste de nomenclaturas.
- Organização das colunas.
- Padronização dos valores categóricos.

---

### 5. Exportação dos Resultados

Geração de um dataset final:

- Limpo
- Consistente
- Estruturado
- Preparado para análises e visualizações

---

## 🚧 Principais Desafios Encontrados

Durante o desenvolvimento do projeto, foram enfrentados desafios comuns em cenários reais de dados:

- Diferentes formatos de datas.
- Valores monetários inconsistentes.
- Registros duplicados.
- Dados incompletos.
- Estruturas distintas entre fontes de dados.
- Extração de informações a partir de HTML.
